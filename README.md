## 3. Technology Stack

- **HTML5:** 100% Semantic markup (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`, `<form>`). Zero frameworks.
- **CSS3:** Custom Properties (`:root`), CSS Grid, Flexbox, hardware-accelerated animations, and responsive media queries (`< 1100px`, `< 768px`).
- **Vanilla JavaScript (ES6+):** Dynamic IST clock, category filtering, accessible modal drawer, real-time input validation, and real working email delivery directly to `saxenaanirudh59@gmail.com` via FormSubmit AJAX.

## 5. How to Run

In your VS Code terminal (inside `portfolio-website`):

```powershell
npx serve .
```

Or open directly in your browser:
```powershell
Start-Process .\index.html
```
